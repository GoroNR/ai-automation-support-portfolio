# Power Automate Portfolio

This section contains my Microsoft Power Automate learning exercises and a practical support ticket automation project.

The exercises focus on workflows used in SaaS Support, Technical Support and support operations.

## Featured project

### Power Automate Support Ticket Automation

An automated support workflow that processes incoming emails, saves ticket information in Excel and OneDrive, applies conditional logic, routes tickets using Switch conditions, requests approvals and updates existing records.

The project also includes retry settings, Configure run after, error handling and TRY/CATCH-style workflow logic.

[View the Power Automate Support Ticket Automation project](projects/02_support_ticket_automation/)
