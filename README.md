### 02 — Power Automate Support Ticket Automation

An automated support workflow built with Microsoft Power Automate.

The workflow processes incoming support emails, stores ticket information in Excel and OneDrive, applies conditional logic, routes requests with Switch actions, requests approvals and updates existing records.

The project also demonstrates:

- Outlook automation,
- Excel Online tables,
- OneDrive integration,
- Conditions and Switch,
- approval workflows,
- Update a row,
- retry policies,
- Configure run after,
- TRY/CATCH-style error handling.

[View the Power Automate Support Ticket Automation](05_projects/02_power_automate_support_ticket_automation/)

### 03 — SQL Support Reporting

A relational SQLite project containing 15 operational reports based on fictional SaaS support data.

The reports analyze:

- ticket categories,
- priority distribution,
- customer activity,
- ticket ownership,
- active workload,
- first response time,
- resolution time,
- monthly support performance.
